The full texts of the source articles are not redistributed in this repository, because they are
copyrighted by their publishers. Each article can be obtained from its publisher through the DOI listed
in `papers_list.csv`.

To re-run the extraction, save one plain-text file per paper in this folder, named `<paper_id>.txt`
(for example `ref10_NK-CDC.txt`; see `paper_txt_template.txt`). These files are ignored by git.
Steps 2-5 of the workflow (dataset, evaluation, figures, baseline) do not need them.
